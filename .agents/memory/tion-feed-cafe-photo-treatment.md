name: Tion Feed cafe photo treatment
description: Visual and content rules for cafe/location slides in Tion Feed.
---

Use each cafe's supplied photo as the source. Keep it photographic and character-free; use AI only for requested image enhancement or object removal while preserving the venue's recognizable architecture, objects, and composition. Keep the original asset unchanged and use only labels supplied by the user.

**Why:** The user asked cafe slides to omit character art, improve photo quality, and preserve each cafe's identity.

**How to apply:** For future cafe slides, edit the supplied image conservatively, retain the original, and use the shared Tion Feed poster treatment with a user-provided venue label.

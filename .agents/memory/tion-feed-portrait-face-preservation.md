---
name: Tion Feed portrait identity
description: Facial identity preservation requirements for AI-edited portraits in Tion Feed.
---

For AI portrait edits in Tion Feed, preserve the subject's recognizable facial shape, features, skin tone, hair, and age. Change clothing, pose, or background without beautifying or reshaping the face. AI likeness is not guaranteed, so inspect each result before using it.

**Why:** The user repeated that their face must not change when the portrait is restyled for a Tion Feed slide.

**How to apply:** Use the supplied portrait as the primary identity reference and compare the result with the source before integrating it. For wardrobe-color-only edits that require an unchanged face, avoid generative image edits; recolor only masked garment pixels and verify facial-region pixels against the original.
